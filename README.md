# Enterprise Server & Traffic Monitoring Lab

An automated local enterprise infrastructure lab built with **Vagrant**, **VirtualBox**, and **Ubuntu 22.04 LTS**. This project demonstrates automated VM provisioning, networking configuration, and infrastructure monitoring.

---

## 🏗️ Architecture Overview

- **OS:** Ubuntu 22.04 LTS (`ubuntu/jammy64`)
- **Virtualization Provider:** Oracle VirtualBox
- **Node Name:** `Office-Server-Node`
- **Private Network IP:** `192.168.56.10`
- **Allocated Hardware:** 1 vCPU, 1024 MB RAM
